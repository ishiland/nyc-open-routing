  <name>Task 2: Harden BottomSheet gesture isolation and map passthrough</name>
  <files>

  <action>
Harden the BottomSheet component for proper gesture isolation from the map:

1. **Add `hideBackdrop` prop** to SwipeableDrawer -- prevents backdrop from blocking map interactions. The sheet itself captures events; the map area around it stays interactive.

2. **Add pointer-events passthrough** on the SwipeableDrawer root sx:
   ```
   pointerEvents: 'none'
   ```
   And re-enable on the drawer paper:
   ```
   '& .MuiDrawer-paper': { pointerEvents: 'auto', ... }
   ```
   This lets touch/click events pass through the drawer's invisible overlay area to the map.

3. **Add `touch-action: none`** to the drag handle Box sx. This prevents the browser from interpreting the drag as a scroll/pan gesture, isolating it from the map's touch handling.

4. **Add `overscrollBehavior: 'contain'`** to the content Box sx (the scrollable area). This prevents iOS Safari bounce-scroll from propagating to the page/map.

5. **Migrate deprecated `ModalProps` pattern** -- The current `ModalProps: { keepMounted: true }` is fine, but also add `slotProps: { backdrop: { invisible: true } }` inside ModalProps for MUI v7 compatibility (alongside hideBackdrop for belt-and-suspenders).

6. **Keep existing functionality intact** -- All drag start/end handlers, snap point logic, swipe hint, and debug indicator must remain unchanged. Only add the isolation props described above.

The final SwipeableDrawer props should include:
- `anchor="bottom"`
- `open={open}`
- `onClose` / `onOpen`
- `disableSwipeToOpen={false}`
- `disableDiscovery` (already present)
- `hideBackdrop` (NEW)
- `sx` with `pointerEvents: 'none'` on root + `pointerEvents: 'auto'` on paper (NEW)
- `ModalProps` with `keepMounted: true` and `slotProps.backdrop.invisible: true` (UPDATED)

The drag handle Box should add `touchAction: 'none'` to its sx.
The content Box should add `overscrollBehavior: 'contain'` to its sx.
