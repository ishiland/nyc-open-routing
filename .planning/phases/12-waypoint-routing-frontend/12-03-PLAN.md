**Prerequisites:** Docker services running with imported LION data. Open http://localhost:3002 in browser.

**Test 1: Existing two-point routing unchanged**
1. Enter a start address (e.g., "350 5th Ave, Manhattan")
2. Enter an end address (e.g., "1 Times Square, Manhattan")
3. Click "Get Directions"
4. Verify: Route displays on map, turn-by-turn directions show in sidebar, summary card shows distance/time
5. Change mode to Bike, Walk — verify route recalculates
6. Click Clear — verify everything resets

**Test 2: Add a waypoint**
1. Enter a start address
2. Click "Add Stop" button (should appear between From/To inputs)
3. Verify: A new "Stop 1" input appears
4. Type an address in the Stop 1 input and select from suggestions
5. Verify: A blue numbered marker ("1") appears on the map
6. Enter an end address
7. Click "Get Directions"
8. Verify: Route line passes through all three points
9. Verify: Turn-by-turn directions show "Leg 1: Origin to Stop 1" and "Leg 2: Stop 1 to Destination" headers
10. Verify: Summary card shows total distance, time, and "2 legs"

**Test 3: Remove a waypoint**
1. With a waypoint route displayed, click the X button on the Stop 1 input
2. Verify: Waypoint marker disappears from map
3. Verify: Route line clears (requires new "Get Directions" click)
4. Click "Get Directions" — verify it uses regular two-point routing now

**Test 4: Swap button disabled**
1. Add a waypoint between start and end
2. Verify: The swap button is disabled (grayed out)
3. Remove the waypoint
4. Verify: The swap button is enabled again

**Test 5: Clear clears everything**
1. Set up a waypoint route (start, waypoint, end)
2. Click "Get Directions" to see the route
3. Click "Clear"
4. Verify: All inputs cleared, all markers removed, route removed, waypoint marker removed

**Test 6: Auto-recalculate**
1. Set up a waypoint route and click "Get Directions"
2. Switch travel mode (e.g., Drive to Bike)
3. Verify: Route recalculates automatically through all three points
