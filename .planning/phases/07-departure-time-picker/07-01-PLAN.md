  <name>Task 1: Create DepartureTimePicker component</name>
  <files>client/src/components/controls/DepartureTimePicker.tsx</files>
  <action>
Create a compact departure time picker component following the existing control patterns (TrafficToggle, FerryToggle).

**State source:** Read `mode`, `useTraffic`, `trafficHour`, `trafficDayOfWeek`, `setTrafficHour`, `setTrafficDayOfWeek` from RoutingContext via useContext. These already exist with localStorage persistence and are already consumed by useRouteFetch, useIsochroneFetch, and useRouteStateSync.

**Visibility:** Return null if `mode !== "drive"` or `useTraffic !== true`. Same pattern as TrafficToggle.

**Default state ("Now"):** When `trafficHour === null && trafficDayOfWeek === null`, display a compact row showing a schedule/clock icon + "Depart: Now" label + a small "Change" text button. This is the collapsed/default state.

**Expanded state:** When user clicks "Change" (or the row), show two inline MUI Select dropdowns:
- Day select: Mon, Tue, Wed, Thu, Fri, Sat, Sun (values 1-7, matching API's day_of_week where Mon=1, Sun=7)
- Hour select: 12 AM, 1 AM, 2 AM, ..., 11 PM (values 0-23, matching API's hour param). Use 12-hour format with AM/PM for display, but store 0-23 integer values.
- Default selections when opening: current day and current hour (from new Date())

**Custom time set state:** When `trafficHour !== null && trafficDayOfWeek !== null`, show the label "Leave at [Day] [Time]" (e.g., "Leave at Wed 3 PM") with a clear/reset IconButton (Close/Clear icon) that sets both values back to null.

**Reset ("Now"):** Clicking the clear button calls `setTrafficHour(null)` and `setTrafficDayOfWeek(null)`, which triggers localStorage removal (already handled in RoutingContext).

**Styling:**
- Match the compact inline style of TrafficToggle (px: 2, py: 0.5, gap: 0.5)
- Use MUI Schedule icon (from @mui/icons-material/Schedule) with color="primary.main"
- Use Typography variant="caption" fontWeight={500} for labels
- Select dropdowns: size="small", variant="standard" (no border/outline for compactness), dense
- Clear button: size="small" IconButton with Close icon
- Keep the whole component very compact — it sits in the controls header area between TrafficToggle and the search inputs

**Accessibility:**
- aria-label on the day and hour selects ("Departure day", "Departure hour")
- aria-label on clear button ("Reset to current time")
- The entire section should have role="group" with aria-label="Departure time selection"

**No animation libraries** — use simple conditional rendering (no framer-motion, no react-spring).
