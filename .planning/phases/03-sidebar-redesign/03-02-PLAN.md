   - Since slotProps replaces both InputProps and inputProps, merge them into one `slotProps` object:
     ```
     slotProps={{
       input: {
         endAdornment: (
           <InputAdornment position="end">
             {/* ... existing geolocation button unchanged ... */}
           </InputAdornment>
         ),
       },
       htmlInput: {
     ```
