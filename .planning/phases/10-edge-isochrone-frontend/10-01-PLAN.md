<task type="auto">
  <name>Task 2: Add edge isochrone service method and route parameter</name>
  <files>api/services/isochrone.py, api/routes/isochrone.py</files>
  <action>
**In `api/services/isochrone.py`:**

1. Import the new schemas: `IsochroneEdgeFeature, IsochroneEdgeProperties` from `models.schemas`.
2. Add a `get_isochrone_edges` method to `IsochroneService`, mirroring the structure of `get_isochrone` but calling edge SQL functions and building edge response objects:
   - Same parameters as `get_isochrone` (orig, mode, intervals, use_traffic, hour, day_of_week).
   - Same cache logic but with `"iso-edges-"` prefix in cache_suffix to avoid collisions with polygon cache.
   - Same coordinate parsing and error handling.
   - SQL function dispatch:
     - `drive`: `SELECT * FROM getdrivingisochrone_edges(:lon, :lat, :intervals, :use_traffic, :hour, :day_of_week)`
     - `bike`: `SELECT * FROM getbikingisochrone_edges(:lon, :lat, :intervals)`
     - `walk`: `SELECT * FROM getwalkingisochrone_edges(:lon, :lat, :intervals)`
   - Build response: for each row, create `IsochroneEdgeFeature` with `IsochroneEdgeProperties(edge_id=row["edge_id"], band_index=row["band_index"], agg_cost=row["agg_cost"], street=row["street"])` and `geometry=dump_geo(row["geom"])`.
   - Same traffic fallback pattern (if traffic data error, retry with use_traffic=False).
   - Return `IsochroneResponse(features=features, origin=origin_geojson)`.

**In `api/routes/isochrone.py`:**

1. Import `IsochroneView` from `models.schemas`.
2. Add a `view` query parameter to the `get_isochrone` endpoint: `view: IsochroneView = Query(default=IsochroneView.POLYGON, description="Visualization type: polygon hulls or edge street segments")`.
3. Dispatch based on `view.value`:
   - If `"polygon"`: call `isochrone_service.get_isochrone(...)` (existing behavior, backward compatible).
   - If `"edges"`: call `isochrone_service.get_isochrone_edges(...)` with same parameters.

The default `view=polygon` ensures full backward compatibility with existing frontend.
