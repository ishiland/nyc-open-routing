Add a new `GET /layer` endpoint to the existing `api/routes/traffic.py` file (which already has the `/api/traffic` prefix router). This endpoint will be at `GET /api/traffic/layer`.

**Query parameters:**
- `bbox: str` — comma-separated `west,south,east,north` (all floats). Required.

**Implementation:**
1. Parse bbox string: split by comma, convert to 4 floats (west, south, east, north). Return 400 if invalid format.
2. Basic validation: west < east, south < north, all values within reasonable bounds (lon -180 to 180, lat -90 to 90).
3. Execute SQL query using `get_db_engine()` dependency (same pattern as IsochroneService):

```python
from sqlalchemy import text
from dependencies import get_db_engine

sql = text("""
    SELECT
        e.id,
        e.street,
        e.traffic_factor,
        e.geom_4326 AS geom
    FROM edges e
    WHERE e.traffic_factor > 1.0
      AND e.driveable = TRUE
      AND e.geom_4326 && ST_MakeEnvelope(:west, :south, :east, :north, 4326)
""")
```

4. Use `dump_geo()` from `utils/geo.py` to convert WKB geometry to GeoJSON (same pattern as isochrone.py).
5. Build `TrafficLayerFeature` for each row with properties `{"id": row.id, "street": row.street, "traffic_factor": float(row.traffic_factor)}`.
6. Return `TrafficLayerResponse(features=features)`.
7. If no rows, return empty features list (NOT a 404 — absence of traffic data in a viewport is normal).

- `from sqlalchemy import text`

**Important:** Use `get_db_engine` as a direct call (not Depends) since it returns the singleton engine — follow the same pattern as IsochroneService which receives the engine in its constructor. Actually, since this is a simple route handler (not a service class), use `Depends(get_db_engine)` to get the engine parameter, then `engine.connect()` inside.

Alternatively, since the existing traffic.py uses `Depends(get_traffic_service)`, and the db_engine is already a singleton, simply import `get_db_engine` and call it directly in the handler. Either approach works; pick whichever is cleaner. The isochrone *service* receives engine via constructor, but for a simple handler, direct import is fine:

```python
from dependencies import get_db_engine

@router.get("/layer")
def traffic_layer(bbox: str = Query(..., description="Bounding box: west,south,east,north")):
    # Parse bbox
    try:
        parts = [float(x.strip()) for x in bbox.split(",")]
        if len(parts) != 4:
            raise ValueError()
        west, south, east, north = parts
    except (ValueError, TypeError):
        raise HTTPException(status_code=400, detail="Invalid bbox format. Expected: west,south,east,north")

    if west >= east or south >= north:
        raise HTTPException(status_code=400, detail="Invalid bbox: west must be < east, south must be < north")

    engine = get_db_engine()
    with engine.connect() as conn:
        result = conn.execute(sql, {"west": west, "south": south, "east": east, "north": north})
        rows = result.fetchall()

    features = []
    for row in rows:
        row_dict = dict(row._mapping)
        features.append(TrafficLayerFeature(
            properties={"id": row_dict["id"], "street": row_dict["street"] or "", "traffic_factor": float(row_dict["traffic_factor"])},
            geometry=dump_geo(row_dict["geom"]),
        ))

    return TrafficLayerResponse(features=features)
```
