      - `ArrowDown`: calls `getNextSnapPoint(snapPoint, "down")` and sets the new snap point; if already at lowest snap point (`BOTTOM_SHEET_SNAP_POINTS[0]`) and going down, call `onClose()` if available

    - Change the drag handle Box from `role="button"` to `role="slider"` since it controls a continuous range
    - Add ARIA attributes to the drag handle: `aria-label="Resize bottom sheet"`, `aria-valuemin={0}`, `aria-valuemax={100}`, `aria-valuenow={Math.round(snapPoint * 100)}`, `aria-valuetext={\`${Math.round(snapPoint * 100)} percent\`}`
    - Add `onKeyDown={handleKeyDown}` to the drag handle Box
    - Keep existing `tabIndex={0}`, `onTouchStart`, `onTouchEnd`, `onMouseDown`, `onMouseUp` handlers

    **A11Y-04 (Focus management) — AdaptiveLayout.tsx:**

    - Create `const expandBtnRef = useRef<HTMLButtonElement>(null)` for the collapse/expand IconButton
    - Add `ref={expandBtnRef}` to the IconButton
    - Update the `onClick` handler to manage focus after collapse/expand:
