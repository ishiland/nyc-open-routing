# Plan 24-01: Create Top-Level Makefile

## Objective

Create a project-wide Makefile at the repo root wrapping docker compose commands so contributors can build, test, lint, format, and manage the project with simple `make` commands.

## Tasks

### Task 1: Create top-level Makefile

Commands to include (DX-01 requirement):
- `make build` — `docker compose build`
- `make up` — `docker compose up -d`
- `make down` — `docker compose down`
- `make test` — Run both API pytest and client vitest
- `make test-api` — `docker compose exec api pytest`
- `make test-client` — `docker compose exec client npm test`
- `make lint` — Run both API flake8 and client eslint
- `make lint-api` — `docker compose exec api make lint`
- `make lint-client` — `docker compose exec client npm run lint:check`
- `make format` — Run both API (black+isort) and client (prettier) formatters
- `make format-api` — `docker compose exec api make format`
- `make format-client` — `docker compose exec client npm run format`
- `make import` — `docker compose exec api sh /data-imports/import-lion.sh 25a`
- `make import-traffic` — `docker compose exec api sh /data-imports/import-lion.sh 25a --download-traffic`
- `make db` — `docker compose exec db psql -U postgres -d routing`
- `make logs` — `docker compose logs -f`
- `make clean` — `docker compose down -v` (destroys data)
- `make help` — List all commands (default target)

### Task 2: Verify Makefile
- `make help` displays all commands
- `make build` runs without errors (don't actually run full build, just verify syntax)

## Notes
- Keep api/Makefile as-is (it's used inside the container)
- Top-level Makefile wraps docker compose, not raw commands
