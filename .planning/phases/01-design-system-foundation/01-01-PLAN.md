Replace the entire contents of `client/src/utils/theme.ts` with a new theme. Key specifications:

**Module augmentation** — Extend MUI's Theme interface to add:
- `modeColors: { drive: string; bike: string; walk: string }` (new)
- `map: { ... }` (preserve existing map property structure exactly)
- `Palette.accent` and `PaletteOptions.accent` for the custom orange palette entry

**Export `MODE_COLORS` constant** — This is the shared source of truth consumed by style.ts:
```typescript
export const MODE_COLORS = {
  drive: "#0039A6",   // MTA Blue
  bike: "#087F23",    // Accessible dark green (5.16:1 vs white)
  walk: "#E65100",    // Accessible dark orange (3.79:1 vs white)
} as const
```

**Palette** (two-pass createTheme for augmentColor):
- `primary.main`: `#0039A6` (MTA Blue), `contrastText`: `#ffffff`
- `secondary.main`: `#EE352E` (MTA Red), `contrastText`: `#000000` (black text — red fails white AA at 4.05:1)
- `accent`: Use `theme.palette.augmentColor({ color: { main: "#FF6319" }, name: "accent" })` in second pass
- `error.main`: `#EE352E`
- `background.default`: `#f5f5f5`, `background.paper`: `#ffffff`
- Keep existing `action.disabledBackground` and `action.disabled` values

**Typography:**
- `fontFamily`: `"'Inter Variable', sans-serif"`
- `fontSize`: `14` (MUI default, NOT 16 — see research pitfall 3)
- `htmlFontSize`: `16`
- Bold heading weights: h1-h3 at 700, h4-h6 at 600
- Tight type scale: h1=2rem, h2=1.75rem, h3=1.5rem, h4=1.25rem, h5=1.125rem, h6=1rem
- body1: 400 weight, 0.9375rem, lineHeight 1.5
- body2: 400 weight, 0.8125rem, lineHeight 1.5
- button: 600 weight, textTransform "none"
- caption: 500 weight, 0.75rem
- overline: 600 weight, 0.6875rem, letterSpacing "0.08em"
- subtitle1: 600 weight, 0.9375rem
- subtitle2: 600 weight, 0.875rem

**Spacing:** `spacing: 6` (6px base for compact transit aesthetic — MUI default is 8px)

**Shape:** `borderRadius: 6`

**Breakpoints:** Keep existing: `{ xs: 0, sm: 600, md: 905, lg: 1240, xl: 1440 }`

**Component overrides** (in second createTheme pass so theme references work):
- `MuiButton`: borderRadius 6, fontWeight 600, textTransform "none", minHeight 44, focus-visible outline 3px solid primary.main with 2px offset, disabled state preserved
- `MuiCard`: elevation 0, borderRadius 8, border "1px solid" with borderColor `theme.palette.divider`
- `MuiPaper`: borderRadius 6
- `MuiIconButton`: minHeight/minWidth 44, focus-visible outline 3px solid primary.main
- `MuiTextField`: input fontSize 16 (iOS zoom prevention)
- `MuiListItemButton`: minHeight 44, focus-visible outline 2px solid primary.main, offset -2px
- `MuiTab`: fontWeight 600, textTransform "none"
- `MuiChip`: fontWeight 600, borderRadius 4

**modeColors:** Use MODE_COLORS constant.

**map:** Preserve existing structure exactly:
```typescript
map: {
  startPoint: { color: "#22c55e" },   // Keep green for start (universal convention)
  endPoint: { color: "#ef4444" },     // Keep red for end (universal convention)
  route: { color: MODE_COLORS.drive, width: 5 },
  point: { radius: 8, blur: 0.15, strokeWidth: 2, strokeColor: "#ffffff" },
}
```

**Important:** Focus-visible outline colors must reference `theme.palette.primary.main` (not hardcoded `#556cd6` from old theme). The map start/end marker colors remain independent of mode colors per research recommendation.

**Do NOT change:** The `cssVariables: true` setting (already exists, must remain).
