Add a new `get_waypoint_route` method to `RoutingService` (at the end of the class, before `_format_route_response`). This method orchestrates per-leg routing by calling existing mode-specific methods.

**Import updates** at the top of the file:
- Add `WaypointRouteResponse, LegResponse, LegSummary, WaypointRouteSummary` to the import from `models.schemas`

**Method signature:**
```python
def get_waypoint_route(
    self,
    waypoints: List[str],
    mode: str,
    use_traffic: bool = True,
    avoid_ferries: bool = False,
    hour: Optional[int] = None,
    day_of_week: Optional[int] = None
) -> WaypointRouteResponse:
```

**Method implementation:**
1. Initialize `legs = []`, `total_distance = 0.0`, `total_time = 0.0`
2. Loop `for i in range(len(waypoints) - 1)`:
   - `orig = waypoints[i]`, `dest = waypoints[i + 1]`
   - Dispatch to existing methods based on `mode`:
     - `"drive"` -> `self.get_driving_route(orig, dest, use_traffic=use_traffic, hour=hour, day_of_week=day_of_week)`
     - `"bike"` -> `self.get_biking_route(orig, dest, avoid_ferries=avoid_ferries)`
     - `"walk"` -> `self.get_walking_route(orig, dest, avoid_ferries=avoid_ferries)`
   - The existing methods return `RouteResponse`. Extract `.features`.
   - If `len(leg_response.features) == 0`: raise `HTTPException(status_code=404, detail=f"No route found for leg {i + 1} (waypoint {i + 1} to waypoint {i + 2}). The entire route cannot be calculated.")`
   - Compute per-leg totals: sum `feature.properties.distance or 0` and `feature.properties.travel_time or 0` across all features in this leg
   - Build `LegResponse(leg=i, summary=LegSummary(distance=leg_distance, travel_time=leg_time), features=leg_response.features)`
   - Accumulate `total_distance` and `total_time`
3. Build and return `WaypointRouteResponse(legs=legs, summary=WaypointRouteSummary(total_distance=total_distance, total_travel_time=total_time, num_legs=len(legs)))`

**Cache integration:**
Before the loop, check cache using a waypoint-specific key:
```python
waypoints_str = "|".join(waypoints)
if mode == "drive":
    if hour is not None and day_of_week is not None:
        cache_suffix = f"traffic-h{hour}-d{day_of_week}" if use_traffic else "no-traffic"
    else:
        cache_suffix = "traffic-static" if use_traffic else "no-traffic"
    cache_key = f"waypoint-drive-{cache_suffix}"
elif mode == "bike":
    cache_key = "waypoint-bike-no-ferry" if avoid_ferries else "waypoint-bike"
elif mode == "walk":
    cache_key = "waypoint-walk-no-ferry" if avoid_ferries else "waypoint-walk"
```
Use `self.cache.get(waypoints_str, "", cache_key)` for lookup (empty string for dest since waypoints_str already contains all points). If cache hit, deserialize back to `WaypointRouteResponse`.

After building the response, cache the complete `WaypointRouteResponse` object: `self.cache.set(waypoints_str, "", cache_key, response)`.

**Critical:** Do NOT modify any existing methods (`get_driving_route`, `get_biking_route`, `get_walking_route`, `_format_route_response`). The `get_waypoint_route` method is purely additive -- it calls existing methods and assembles results.

**Error handling:** Let HTTPExceptions from the underlying mode-specific methods propagate naturally. The 404 from an empty leg is the only new error case. Wrap the entire loop in a try/except that catches non-HTTP exceptions and raises `HTTPException(status_code=500, detail="Error processing waypoint route request.")`.
