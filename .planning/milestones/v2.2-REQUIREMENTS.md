## v2.2 Requirements

### Edge-Based Isochrones

- [x] **ISO-01**: SQL isochrone functions return reachable edge geometries with cumulative travel time — Phase 9
- [x] **ISO-02**: User can toggle between polygon and edge-based isochrone visualization — Phase 10
- [x] **ISO-03**: Edge-based isochrone displays reachable streets colored by time band (5/10/15/20 min) — Phase 10
- [x] **ISO-04**: Edge-based isochrones work for all three modes (drive, bike, walk) and respect traffic settings — Phase 10

- [x] **WAY-02**: Route calculates through all waypoints in order with per-leg directions — Phase 11
- [x] **WAY-03**: Waypoint markers display on the map at each stop — Phase 12
- [x] **WAY-04**: User can remove individual waypoints — Phase 12
